# Project Init

## When to use
Use when the user wants to initialize this repo or set up the local dev environment.

## Minimal commands
```bash
# 1) Create venv (if missing)
python3 -m venv .venv

# 2) Activate venv
source .venv/bin/activate
```

## Notes
- Keep steps concise and avoid extra tooling unless requested.
- Prefer `python3` on macOS.
